# Kaggle Stats API

Dynamic Kaggle stats card generator for GitHub README files.

## 🚀 Usage in your GitHub README:

`markdown
![Kaggle Stats](https://your-vercel-app.vercel.app/api/kaggle?username=anadiskt)
`

## 📦 Deploy to Vercel:

1. Fork this repository
2. Connect to Vercel
3. Deploy automatically
4. Use the generated URL in your README

## 🎯 Features:

- Dynamic SVG generation
- Shows Kaggle tier, points, datasets, notebooks, competitions
- Auto-updates every 30 minutes
- Dark/light theme support
- Mobile-friendly

## 🔧 Local Development:

`ash
node api/kaggle.js
`

Visit: http://localhost:3000/api/kaggle

## 📊 Example:

Your card will show:
- Kaggle tier and points
- Number of datasets
- Number of notebooks
- Competition participation
- Follower count
- Activity visualization
